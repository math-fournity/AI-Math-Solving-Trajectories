# 工作笔记 · 轮次 1 · p27-full-deepmath_103k_00000928

题目：A、B 是 C*-代数，ψ: A → B 不是 *-同态（non *-homomorphism），b ∈ B 非零正规元。
已知连续函数演算给出 *-等距同构 φ: C(σ_B(b)) → C*(b,b*)，f ↦ f(b)。
问：是否存在 f ∈ C(σ_B(b)) 与 a ∈ A 使 ψ(a) = f(b) ≠ 0？

## 已确认结论

**结论：答案是否定的（No）。这样的 f 和 a 不必存在。**

问题的等价形式：由于 φ 是到上的，{f(b) : f ∈ C(σ_B(b))} = C*(b,b*)，
所以题目等价于问"ψ(A) ∩ C*(b,b*) 是否必含非零元"。
题面没有给任何连接 ψ 的像与 b 的条件，这个相交完全可以是 {0}。

**主反例（对应题面字面读法）**：
- A = ℂ，B = M₂(ℂ)，ψ(λ) = λ·e₁₂（e₁₂ = [[0,1],[0,0]]），b = e₁₁ = [[1,0],[0,0]]。
- ψ 不是 *-同态：乘法性失败（ψ(1)² = e₁₂² = 0 ≠ e₁₂ = ψ(1·1)）；保 * 也失败（ψ(1)* = e₂₁ ≠ e₁₂）。ψ 还是线性连续映射，是"规规矩矩的非 *-同态"，不是病态构造。
- b 非零、自伴（故正规）；σ_B(b) = {0,1}（det(tI−b) = t(t−1)）。
- C*(b,b*) = C*(b) = {αe₁₁ + βe₂₂}（对角矩阵代数）；f(b) = f(1)e₁₁ + f(0)e₂₂。
- 方程 λe₁₂ = αe₁₁ + βe₂₂ 比较 (1,2)-元得 λ = 0，故 ψ(a) = f(b) 强制 f(b) = 0。无非零解。

**稳健性（覆盖"non *-homomorphism"的各种读法，全部 No）**：
- 反例 2：若读成"非零 *-同态"——ψ(λ) = λp，p = ½[[1,1],[1,1]]（投影，非酉非零 *-同态），b = diag(1,−1)，λp 对角 ⇔ λ = 0。
- 反例 3：若读成"保乘法但不保 * 的同态"——ψ(λ) = λq，q = [[1,1],[0,0]]（q² = q 但 qᵗ ≠ q），b = e₁₁，λq 对角 ⇔ λ = 0。
- 何时平凡地 Yes：若 1_B ∈ ψ(A)（如酉 *-同态），常函数 f ≡ c 给 f(b) = c·1_B = ψ(c·1_A)；若 ψ 满，取 f(t)=t 与原像。"非 *-同态"恰好堵死这两条通路。
