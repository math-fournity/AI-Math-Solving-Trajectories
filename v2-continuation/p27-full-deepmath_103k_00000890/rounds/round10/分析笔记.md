## 一、题目与全局状态

**题面**：给定 P(x₁,…,xₙ) ∈ ℝ[x₁,…,xₙ]，问：是否存在算法判定「是否存在非零多项式 Q 使 PQ 的系数全非负」？可判定性问题。

**★ 猜想 H 已被轮次9 修正为"因子级判据"（重要！旧 H 的字面表述是错的）**：

记 Y = {P ≢ 0 : ∃Q≢0, PQ⪰0}。则正确的刻画应是：

> **因子判据**：P ∈ Y ⟺ P 的每个不可约因子 p 满足「Z(p) ∩ [0,∞)ⁿ∖{0} = ∅ **或** p ~ c·x^m（单项式）」。

为什么旧 H（"P 在闭象限去掉原点上无零点"）字面为假：n≥2 时 P=x₁ 在整个坐标面 {x₁=0}∖{0} 上有零点，但 x₁∈Y（取 Q=1）。旧 H 只在 n=1 恰好正确。轮次1 的例子表全部与因子判据相容（它的反例都没有纯单项式因子），但**表述必须升级为因子级**。

**解集候选清单（按可信度排序）**：

1. **必要性方向（⟹）**：可信度：极高——轮次9 给出了完整证明（见第二节 C），只在最后一步多变量切片索引的收尾检查上被预算截断（缺口平凡，见第四节）。
2. **充分性方向（⟸），不可约且无零点的 p ⟹ p∈Y**：**开放**。这是全问题仅存的缺口。单变量情形已完全解决。
3. **答案 = 可判定 YES**（条件性）：若 2 成立，判定算法 = 在 ℝ[x] 做有效不可约分解 + 用 CAD/Tarski–Seidenberg 判每个因子「Z(p)∩[0,∞)ⁿ∖{0}=∅」。两者皆算法可行。

## 二、当前前沿

轮次9 的推理链条分四块，前三块已完成。

### A. 预备引理（直接可用）

- **常号引理**：P 在 [0,∞)ⁿ∖{0} 无零点 ⟹ P 在其上恒正或恒负（连通性论证，对 n≥1 都成立）。因此 (⟸) 可 WLOG 设 P≻0 于闭象限去掉原点。
- **Z(W) 的面结构**：若 W⪰0 且 W(a)=0（a∈闭象限，S(a)=a 的零坐标集），则 W 的每个单项式都含 S(a) 中某变量的幂 ⟹ W 在整个坐标面 F_{S(a)} 上恒零。故 **Z(W)∩闭象限恰为若干坐标面之并**（可以是空集或仅{原点}）。

### B. UFD 因子归约（已证）

Y 对乘法封闭；且 P∈Y ⟺ P 的每个不可约因子 ∈ Y。（⟸：各因子取见证 Qᵢ，乘起来；⟹：P | W⪰0 则每个不可约因子整除 W。）于是**只需刻画不可约多项式**。

### C. 必要性 (⟹) 的完整归纳证明（轮次9 的主成果）

**命题 Γ(n)**：p 不可约，h≢0，p·h⪰0 ⟹ Z(p)∩[0,∞)ⁿ∖{0}=∅ 或 p~c·x_i^e。

证明骨架（强归纳于 n）：
- **内部零点**（u≫0）：赋值论证。0=(ph)(u)=Σc_j u^j，各项≥0 且 u^j>0 ⟹ ph≡0，矛盾。
- **边界零点** u=(b,0_k)，b≫0 ∈ ℝ^{n−k}（k≥1；置换坐标归到此形）。写 p=Σ_α x''^α p_α(x')，h=Σ_β x''^β h_β(x')，其中 x' 是 u 的正坐标（维数 n−k≥1），x'' 是零坐标（k 个变量）。
  - 若 p_0 := p|_{x''=0} ≡ 0：p 在 {x''=0}∩象限（Zariski 稠于该线性子空间）上恒零 ⟹ 每个 x''_i 整除 p ⟹ p~单项式，排除。
  - 否则 p_0≢0 且 p_0(b)=0，b ∈ 原象限∖{0}。取 h 的支撑中最小多重指标 g（对 ℕ^k 的自然偏序；Dickson 引理保证存在）。**第 g 层切片** R_g := [x''^g](ph) = Σ_{α+β=g} p_α h_β。由 g 的极小性，β<g 的 h_β≡0，故 R_g = p_0·h_g；又 ph⪰0 ⟹ 切片 R_g⪰0；且 h_g≢0。这与 dim n−1 的归纳假设矛盾。证毕。
- **n=1 底座**：p(ρ)=0, ρ>0 ⟹ 同一赋值论证。

结合 B：一般必要性 = 「P∈Y ⟹ 每个非单项式不可约因子在闭象限去掉原点内无零点」。

### D. 单变量充分性（已证，含有效界）

构造：q_N(t) = e^{at} 的截断（a>0 任取，配合 negation 保证首项系数为正）。逐系数验证 [t^j](p·q_N) ≥ 0 对 N 充分大成立；受扰动的只是顶部 j∈{N+1,…,N+d}（d=deg p）个系数，由首项 p_d>0 主导，例如 deg 2 例算出 c_{N+1} = a^{N−1}/N!·(N−3a) ≥ 0 当 N≥3a。**单变量：∃Q ⟺ p 无正根（原点豁免），双向初等、完全、带显式界。**

多变量对应物：Q_N = 截断 e^{⟨a,x⟩}，系数条件为 Σ_i p_i a^{j−i}/(j−i)! ≥ 0 ∀j（向量阶乘）。**已代数验证的成功案例：P=x²−xy+y²，取 a₁=a₂ 即可**（归结为 j₁(j₁−1)+j₂(j₂−1) ≥ j₁j₂ ∀j₁,j₂≥2，在 (2,2) 取等，二次型正定保证成立）。但一般多变量情形**没有证明**——这是当前唯一的开放前沿。轮次9 死前的计划是"用 exponential/Pólya 杂交攻 (⟸)"，尚未展开即被截断。

## 三、死路清单

1. **旧 H 的字面表述（集合级判据"P 在闭象限∖{0} 无零点"）** — n≥2 被 P=x₁ 证伪（面上有零点但在 Y）。必须换成因子级判据。
2. **中间候选"集合级判据：Z(P)∩闭象限∖{0} 是若干坐标面之并 ⟺ P∈Y"** — 被共谋反例证伪：P = y·(x²−x+y²+¼)（star 多项式乘 y），零集=整张面 {y=0}，确为面之并，但 star 因子∉Y ⟹ P∉Y。因子级才存活。
3. **S^N 直接作乘子（S=1+x₁+⋯+xₙ）解决多变量 (⟸)** — 不足够：边界/原点/无穷多尺度问题无法用一个 S^N 同时压住（#006 段结论）。Pólya 只在单纯形上好用。
4. **齐次层分裂**（把 P 分层，各层单独找乘子再相乘组合）— 技术上"每层各自∈Y ⟹ 和∈Y"的组合引理成立，但"P≻0 ⟹ 各齐次层在正向球面上 ≥0"只有启发式论证（最高/最低层确实如此，中间层未定），路线未走通即放弃。
5. **线限制法证必要性**（过 u 取射线化到单变量）— 卡在 Q∘L 可能恒零；已被 C 的切片归纳取代，不必回头。
6. （承前几轮，仍然有效）**对偶锥 λ 的逐个判定 / 直接判 C_L 成员资格** — 撞线性递推 Positivity Problem（阶≥6 open），绕开存在性结构而非逐 λ 判定；**凭记忆定位文献出处** — 轮次1 已弃疗，勿重烧预算。
7. **注意**：轮次9 未推翻轮次1 的对偶紧致性论证卡点（逃逸情形未完成）；那条路仍是备选，但 C 的成功使它优先级下降。

## 四、明确的下一步缺口

**当前唯一卡点：(⟸) 多变量充分性——不可约 p，Z(p)∩闭象限∖{0}=∅ ⟹ ∃Q≠0, pQ⪰0。**

攻击建议（按预期收益排序）：

1. **截断指数法的系统分析（最接近已有成功案例）**。目标：找 a∈ℝ₊ⁿ 使 c_j := Σ_i p_i a^{j−i}/(j−i)! ≥ 0 ∀j。注意 c_j = (1/j!)·(d/dt)^j[P(t)e^{⟨a,t⟩}]|₀ 的多元类比，也与 P 的微分算子作用有关。先做数值实验（Python 随机采样无零点不可约 p，搜索可行的 a；轮次9 有 3 次工具调用疑似就是此类实验）。若对某类 p（如严格正定型）能证 a 存在，再向一般情形推进。核对基准：x²−xy+y² 需要 a₁=a₂（不等式在 (2,2) 处取等的刚性值得深挖——它暗示 a 的选择受低次系数约束）。
2. **Pólya + 多尺度拼装**。P≻0 于闭象限∖{0} ⟹ 其最高齐次部在正向球面严格正、各初始形式在相应面单纯形上严格正（由 A 的常号引理 + 极限论证）。对每个"无穷远方向/边界面"用 Pólya 定理定制乘子，再用 B 的乘法封闭性拼接。关键难点（轮次9 明确指出）：象限不紧致，原点附近与无穷远处需要分开处理的设备，而系数条件不局部——需要找到正确的拼接机制（轮次9 尝试过的"A+B 支撑分解""两乘子复合"都失败，见死路 4；建议从初始形式继承条件入手，即轮次1 的 in_w(P) 继承观察）。
3. **先花少量预算封死 C 的最后缺口 + 回归测试**。(i) 把 C 的切片 peeling 用多重指标偏序正式写完（g 取 supp(h) 的极小元即可，Dickson 保证存在；尾部截断处正是这个检查）。(ii) 用因子判据重跑轮次1 全部例子表 + 新增压力测试：P=x−y+1（H 预测 ∉Y？注意 −y+1 在正实轴有根 t=1 ⟹ 单变量部分已判 ∉Y ✓）、任意含单项式因子的混合积、x²+y² 与 (x²+y²)(x+y+1)。确认无反例后再投入主线。
