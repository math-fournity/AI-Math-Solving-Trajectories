An infinite sequence of integers \(A=\left(a_{1}, a_{2}, \ldots\right)\) is called strange if for every natural number \(n>100\), the number \(a_{n}\) is equal to the sum of the products \(a_{k} a_{\ell}\), for which \(1 \leq k<\ell \leq n-1\) and \(k+\ell \geq n, k, \ell \in \mathbb{N}\). Let \(S(A)\) be the set of indices \(n\) for which \(a_{n}\) is an odd number. Find the minimum integer \(N\) with the following property: for any strange sequence \(A\) with \(|S(A)| \geq N\), it follows that the set \(S(A)\) is infinite.
