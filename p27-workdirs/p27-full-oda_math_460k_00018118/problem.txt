During the act of impact one has the boundary-value problem for the longitudinal displacements $u(x, t)$ of points of the rod\n\n$$\nu_{tt} = a^2 \nu_{xx}, \quad 0 < x < l, \quad 0 < t < +\infty, \tag{1}$$\n\n$$\nu(0, t) = 0, \quad 0 < t < +\infty, \tag{2}$$\n\n$$M_u \nu_{tt}(l, t) = -E S \nu_x(l, t), \quad 0 < t < t_0, \tag{2'}$$\n\nwhere $t_0$ is the time of completion of the act of impact\n\n$$\nu(x, 0) = 0, \quad 0 < x < l, \tag{3}$$\n\n$$\nu_t(x, 0) = \n\begin{cases} \n0, \quad 0 \leq x < l, \\\n-v_0, \quad x = l.\n\end{cases} \tag{3'}$$\n\nThe time $t_0$ is characterized by the fact that for $0 < t < t_0$, $\nu_x(l, t)$ must be < 0, and for $t = t_0$, $\nu_x(l, t) = 0$.
