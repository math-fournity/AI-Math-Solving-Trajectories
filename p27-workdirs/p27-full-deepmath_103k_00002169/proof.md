# Proof: Existence of a Non-Principal Relative Discriminant

## Answer

$$\boxed{\text{Yes}}$$

There exists an extension of number fields $L/K$ such that the relative discriminant ideal $d_{L/K}$ is not principal.

## Construction

Let $K = \mathbb{Q}(\sqrt{-23})$ and $L = K(\sqrt{-4+\sqrt{-23}})$.

We will show that $d_{L/K}$ is not principal in $\mathcal{O}_K$.

## Step 1: Basic Facts About $K = \mathbb{Q}(\sqrt{-23})$

The discriminant of $K$ is $d_K = -23$ (since $-23 \equiv 1 \pmod{4}$). The ring of integers is $\mathcal{O}_K = \mathbb{Z}[\omega]$ where $\omega = \frac{1+\sqrt{-23}}{2}$, with minimal polynomial $x^2 - x + 6$ and norm form $N(a+b\omega) = a^2 + ab + 6b^2$.

The class number is $h(K) = 3$ (a classical result; $-23$ is a Heegner number), so $\operatorname{Cl}(K) \cong \mathbb{Z}/3\mathbb{Z}$. Let $g$ denote a generator.

**Minkowski bound:** $M_K = \frac{2}{\pi}\sqrt{23} \approx 3.05$, so the class group is generated by prime ideals of norm $\leq 3$.

**Splitting of 2:** Since $-23 \equiv 1 \pmod{8}$, the prime $2$ splits: $(2) = \mathfrak{p}_1 \mathfrak{p}_2$ with $N(\mathfrak{p}_i) = 2$. Explicitly, $\mathfrak{p}_1 = (2, \omega)$ and $\mathfrak{p}_2 = (2, \omega-1)$ (from $x^2 - x + 6 \equiv x(x-1) \pmod{2}$). Each $K_{\mathfrak{p}_i} \cong \mathbb{Q}_2$ (since $e_i = f_i = 1$).

**Splitting of 3:** Since $-23 \equiv 1 \pmod{3}$, the prime $3$ splits: $(3) = \mathfrak{q}_1 \mathfrak{q}_2$ with $N(\mathfrak{q}_i) = 3$. Explicitly, $\mathfrak{q}_1 = (3, \omega)$ and $\mathfrak{q}_2 = (3, \omega-1)$ (from $x^2 - x + 6 \equiv x(x-1) \pmod{3}$).

**Non-principality:** There is no element of norm $2$ or $3$:
- $N(a+b\omega) = a^2+ab+6b^2 = 2$: checking $b=0$ gives $a^2=2$ (no); $b=\pm 1$ gives $a^2 \pm a + 4 = 0$ with discriminant $-15 < 0$ (no).
- $N(a+b\omega) = 3$: similarly, $b=\pm 1$ gives $a^2 \pm a + 3 = 0$ with discriminant $-11 < 0$ (no).

So $\mathfrak{p}_1, \mathfrak{p}_2, \mathfrak{q}_1, \mathfrak{q}_2$ are all non-principal.

## Step 2: Determining the Classes

Set $[\mathfrak{p}_1] = g$ (the generator of $\operatorname{Cl}(K) \cong \mathbb{Z}/3\mathbb{Z}$). Then:

- $[\mathfrak{p}_2] = [\mathfrak{p}_1]^{-1} = g^2$ (since $(2) = \mathfrak{p}_1\mathfrak{p}_2$ is principal).
- $N(\omega) = 6 = 2 \cdot 3$, and $\omega \in \mathfrak{p}_1 \cap \mathfrak{q}_1$, so $(\omega) = \mathfrak{p}_1 \mathfrak{q}_1$. Thus $[\mathfrak{q}_1] = [\mathfrak{p}_1]^{-1} = g^2$.
- $[\mathfrak{q}_2] = [\mathfrak{q}_1]^{-1} = g$ (since $(3) = \mathfrak{q}_1\mathfrak{q}_2$ is principal).

**A prime above 13:** Since $-23 \equiv 3 \pmod{13}$ and $3$ is a quadratic residue mod $13$ ($4^2 \equiv 3 \pmod{13}$), the prime $13$ splits: $(13) = \mathfrak{r}_1 \mathfrak{r}_2$ with $\mathfrak{r}_1 = (13, \omega-9)$, $\mathfrak{r}_2 = (13, \omega-5)$.

There is no element of norm $13$ ($a^2+ab+6b^2=13$ has no integer solutions: $b=1$ gives $a^2+a-7=0$ with discriminant $29$, not a perfect square; $b=2$ gives negative discriminant). So $\mathfrak{r}_1, \mathfrak{r}_2$ are non-principal.

Now $N(4+\omega) = 16+4+6 = 26 = 2 \cdot 13$. Since $4+\omega \equiv 0 \pmod{\mathfrak{p}_1}$ (as $\omega \equiv 0$) and $4+\omega \equiv 4+9 = 13 \equiv 0 \pmod{\mathfrak{r}_1}$, we get $(4+\omega) = \mathfrak{p}_1 \mathfrak{r}_1$. Thus $[\mathfrak{r}_1] = [\mathfrak{p}_1]^{-1} = g^2$ and $[\mathfrak{r}_2] = g$.

**Summary of classes:**

| Ideal | Norm | Class |
|-------|------|-------|
| $\mathfrak{p}_1 = (2,\omega)$ | 2 | $g$ |
| $\mathfrak{p}_2 = (2,\omega-1)$ | 2 | $g^2$ |
| $\mathfrak{q}_1 = (3,\omega)$ | 3 | $g^2$ |
| $\mathfrak{q}_2 = (3,\omega-1)$ | 3 | $g$ |
| $\mathfrak{r}_1 = (13,\omega-9)$ | 13 | $g^2$ |
| $\mathfrak{r}_2 = (13,\omega-5)$ | 13 | $g$ |

## Step 3: The Element $\alpha = -4 + \sqrt{-23}$

Set $\alpha = -4 + \sqrt{-23} = -5 + 2\omega \in K$.

**Norm:** $N_{K/\mathbb{Q}}(\alpha) = (-4+\sqrt{-23})(-4-\sqrt{-23}) = 16+23 = 39 = 3 \cdot 13$.

**Ideal factorization:** $(\alpha)$ has norm $39 = 3 \cdot 13$. Checking divisibility:
- $\alpha \equiv -5 \equiv 1 \pmod{\mathfrak{q}_1}$ (since $\omega \equiv 0$): $\mathfrak{q}_1 \nmid (\alpha)$.
- $\alpha \equiv -5+2 = -3 \equiv 0 \pmod{\mathfrak{q}_2}$ (since $\omega \equiv 1$): $\mathfrak{q}_2 \mid (\alpha)$.
- $\alpha \equiv -5+18 = 13 \equiv 0 \pmod{\mathfrak{r}_1}$ (since $\omega \equiv 9$): $\mathfrak{r}_1 \mid (\alpha)$.
- $\alpha \equiv -5+10 = 5 \not\equiv 0 \pmod{\mathfrak{r}_2}$ (since $\omega \equiv 5$): $\mathfrak{r}_2 \nmid (\alpha)$.

Therefore $(\alpha) = \mathfrak{q}_2 \mathfrak{r}_1$, and $[\mathfrak{q}_2][\mathfrak{r}_1] = g \cdot g^2 = g^3 = 1$, confirming this is principal.

## Step 4: The Quadratic Extension $L = K(\sqrt{\alpha})$

Since $\alpha$ is not a square in $K_{\mathfrak{p}_1}$ (shown below), $\alpha$ is not a square in $K$, so $L/K$ is a genuine quadratic extension.

### Tame ramification (primes not dividing 2)

For a prime $\mathfrak{r} \nmid 2$, the extension $K(\sqrt{\alpha})/K$ is ramified at $\mathfrak{r}$ if and only if $v_{\mathfrak{r}}(\alpha)$ is odd, with discriminant exponent $1$.

From $(\alpha) = \mathfrak{q}_2 \mathfrak{r}_1$ (squarefree), the primes with odd valuation are exactly $\mathfrak{q}_2$ (above $3$) and $\mathfrak{r}_1$ (above $13$). Both are tame (since $3, 13 \nmid 2$), each contributing exponent $1$.

**No other odd prime ramifies**, since $v_{\mathfrak{r}}(\alpha) = 0$ for all other primes $\mathfrak{r} \nmid 2$.

### Wild ramification (primes above 2)

Since $K_{\mathfrak{p}_i} \cong \mathbb{Q}_2$ for each $i$, we use the criterion: a $2$-adic unit $u$ is a square in $\mathbb{Q}_2$ if and only if $v_2(u-1) \geq 3$ (equivalently, $u \equiv 1 \pmod{8}$).

For a quadratic extension $\mathbb{Q}_2(\sqrt{u})/\mathbb{Q}_2$ with $u$ a unit that is not a square:
- If $u \equiv 3 \pmod{4}$ (i.e., $v_2(u-1) = 1$): the discriminant exponent is $v_2(d) = 2$.
- If $u \equiv 5 \pmod{8}$ (i.e., $v_2(u-1) = 2$): the extension is unramified, $v_2(d) = 0$.

**At $\mathfrak{p}_1$:** In $K_{\mathfrak{p}_1} \cong \mathbb{Q}_2$, $\omega$ maps to the root $\omega_1$ of $x^2 - x + 6 = 0$ with $\omega_1 \equiv 0 \pmod{2}$. Since the two roots sum to $1$, $\omega_1 = 1 - \omega_2$ where $\omega_2 \equiv 1 \pmod{2}$ is the other root.

Writing $\omega_2 = 1 + 2a$ with $a \in \mathbb{Z}_2$ (from $2a^2 + a + 3 = 0$), we get $\omega_1 = -2a$.

Then $\alpha = -5 + 2\omega_1 = -5 - 4a$, and:
$$\alpha - 1 = -6 - 4a = -2(3 + 2a)$$

Since $a \equiv 1 \pmod{2}$, we have $3 + 2a \equiv 5 \equiv 1 \pmod{2}$, so $v_2(3+2a) = 0$. Therefore:
$$v_2(\alpha - 1) = 1$$

So $\alpha \equiv 3 \pmod{4}$, which means $\alpha$ is **not** a square in $K_{\mathfrak{p}_1} \cong \mathbb{Q}_2$. The extension ramifies at $\mathfrak{p}_1$ with **discriminant exponent $2$**.

**At $\mathfrak{p}_2$:** In $K_{\mathfrak{p}_2} \cong \mathbb{Q}_2$, $\omega$ maps to $\omega_2 = 1 + 2a$ where $a = \frac{s-1}{4}$ and $s = \sqrt{-23} \in \mathbb{Q}_2$ with $s \equiv 1 \pmod{4}$.

Then $\alpha = -5 + 2\omega_2 = -3 + 4a$, and:
$$\alpha - 1 = -4 + 4a = 4(a-1)$$

Now $a = \frac{s-1}{4}$, so $a - 1 = \frac{s-5}{4}$. Since $s \equiv 5 \pmod{8}$ (from the Hensel lifting: $s = 5 + 8c$ with $c$ odd), we get $v_2(s-5) = 3$, hence $v_2(a-1) = 1$.

Therefore:
$$v_2(\alpha - 1) = 2 + v_2(a-1) = 2 + 1 = 3$$

So $\alpha \equiv 1 \pmod{8}$, which means $\alpha$ **is** a square in $K_{\mathfrak{p}_2} \cong \mathbb{Q}_2$. The extension does **not** ramify at $\mathfrak{p}_2$.

## Step 5: Computing the Relative Discriminant

Combining all contributions:

$$d_{L/K} = \mathfrak{p}_1^2 \cdot \mathfrak{q}_2 \cdot \mathfrak{r}_1$$

The ramified primes are:
- $\mathfrak{p}_1$ (wild, exponent $2$)
- $\mathfrak{q}_2$ (tame, exponent $1$)
- $\mathfrak{r}_1$ (tame, exponent $1$)

No other primes ramify.

## Step 6: The Class of the Discriminant

Computing in $\operatorname{Cl}(K) \cong \mathbb{Z}/3\mathbb{Z}$:

$$[d_{L/K}] = [\mathfrak{p}_1]^2 \cdot [\mathfrak{q}_2] \cdot [\mathfrak{r}_1] = g^2 \cdot g \cdot g^2 = g^5 = g^2$$

Since $g$ has order $3$, we have $g^5 = g^{5 \bmod 3} = g^2 \neq 1$.

Therefore $d_{L/K}$ is **not principal**.

## Step 7: Verification via Norm Formula

As a consistency check, we verify the norm formula $d_L = d_K^{[L:K]} \cdot N_{K/\mathbb{Q}}(d_{L/K})$:

- $d_K = -23$, $[L:K] = 2$, so $d_K^2 = 529$.
- $N_{K/\mathbb{Q}}(d_{L/K}) = N(\mathfrak{p}_1)^2 \cdot N(\mathfrak{q}_2) \cdot N(\mathfrak{r}_1) = 2^2 \cdot 3 \cdot 13 = 156$.
- $d_L = 529 \cdot 156 = 82524 = 2^2 \cdot 3 \cdot 13 \cdot 23^2$.

The element $\beta = \sqrt{\alpha} = \sqrt{-4+\sqrt{-23}}$ satisfies $\beta^4 + 8\beta^2 + 39 = 0$, with polynomial discriminant $\operatorname{disc}(x^4+8x^2+39) = 5281536 = 64 \cdot 82524$. The index $[\mathcal{O}_L : \mathbb{Z}[\beta]] = 8$ (consistent with wild ramification at $2$), confirming $d_L = 82524$.

## Conclusion

The extension $L = \mathbb{Q}(\sqrt{-23}, \sqrt{-4+\sqrt{-23}})$ over $K = \mathbb{Q}(\sqrt{-23})$ has relative discriminant:

$$d_{L/K} = \mathfrak{p}_1^2 \cdot \mathfrak{q}_2 \cdot \mathfrak{r}_1$$

whose class in $\operatorname{Cl}(K) \cong \mathbb{Z}/3\mathbb{Z}$ is $g^2 \neq 1$, hence $d_{L/K}$ is not principal.

$$\boxed{\text{Yes}}$$
