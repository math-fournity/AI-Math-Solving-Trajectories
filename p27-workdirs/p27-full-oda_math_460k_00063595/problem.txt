4. Given a positive integer $N \geqslant 3$. If a set of $N$ points, each either red or blue, on the coordinate plane has each point with a unique x-coordinate, then the set of points is called "acceptable". $P(x)$ is a polynomial, and $A$ is an acceptable set. If the upper side of the graph of $P(x)$ contains no red points and the lower side contains no blue points, or the upper side contains no blue points and the lower side contains no red points, then $P(x)$ is said to "distinguish" the set $A$. It is known that any acceptable set can be distinguished by a polynomial of degree not exceeding $k$. Find the minimum value of $k$.
