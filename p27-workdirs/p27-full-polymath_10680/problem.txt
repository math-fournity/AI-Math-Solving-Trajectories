In a futuristic data-management facility, there are $n$ distinct server clusters ($n \geq 2$). Each cluster is filled with various data packets. The size of every individual packet is strictly a power of 2 (i.e., $2^k$ gigabytes for some non-negative integer $k$). While a cluster may contain multiple packets of the same size, the configuration of sizes can vary between clusters. However, there is one strict rule: the total aggregate data size (the sum of all packet sizes) must be exactly the same for every one of the $n$ clusters.
