Consider the interval $[0,1]$ equipped with the Lebesgue measure. A measurable function $f$ is non-decreasing on a set of full measure if there exists a set $E$ with $\mu(E) = 1$ such that for all $y, z \in E$, if $z \leq y$, then $f(z) \leq f(y)$. If $f$ is not non-decreasing on a full-measure set, does there exist a real number $x \in [0,1]$, and subsets $A \subseteq [0,x]$ and $B \subseteq [x,1]$, where both $A$ and $B$ have positive Lebesgue measure, such that $f(z) > f(y)$ for every $z \in A$ and $y \in B$?
