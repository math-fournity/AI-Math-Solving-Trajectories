There are $n=100$ students, each having $r=10$ distinct positive integers. All $nr = 1000$ integers are distinct. We wish to partition these $n$ students into $k$ classes such that if a student $A$ in a class has the number $m$, then no other student $B$ in the same class has a number $l$ such that $(m-1)! < l < (m+1)! + 1$. Determine the minimum value of $k$ that is guaranteed to work for any such set of $1000$ integers.
