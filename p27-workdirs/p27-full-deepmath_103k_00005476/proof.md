# Wielandt's Theorem: Maximum Primitivity Exponent

## Problem

For a matrix $M \in \mathbb{R}^{n \times n}_{\geq 0}$ with nonneg entries, define $m$ as the smallest positive integer such that all entries of $M^m$ are strictly positive, if such an $m$ exists. Determine the maximum possible finite value of $m$ over all choices of $M$.

## Answer

$$\boxed{(n-1)^2 + 1}$$

---

## Proof

### 0. Preliminaries and Reformulation

A nonneg square matrix $M$ is called **primitive** if $M^k > 0$ (all entries strictly positive) for some positive integer $k$. The smallest such $k$ is the **primitivity exponent** $\gamma(M)$. The problem asks for $\max\{\gamma(M) : M \text{ is primitive } n \times n\}$.

Associate to $M$ the directed graph $G(M)$ on vertices $\{1, \ldots, n\}$ with an edge $i \to j$ iff $M_{ij} > 0$. Then $(M^k)_{ij} > 0$ iff there is a walk from $i$ to $j$ of length $k$.

A nonneg matrix is primitive iff its graph is **strongly connected** (irreducible) and **aperiodic** (gcd of all cycle lengths is 1). We prove:

> **Theorem (Wielandt, 1950).** For every primitive $n \times n$ nonneg matrix $M$, $\gamma(M) \leq (n-1)^2 + 1$, and this bound is achieved.

---

### 1. Lower Bound: The Wielandt Matrix

**Construction.** Define the $n \times n$ matrix $W$ (for $n \geq 2$) by:
- $W_{i,i+1} = 1$ for $i = 1, \ldots, n-1$ (superdiagonal),
- $W_{n,1} = 1$ (bottom-left corner),
- $W_{n,2} = 1$ (extra entry),
- all other entries $0$.

The graph $G(W)$ has edges $i \to i{+}1$ for $i < n$, plus $n \to 1$ and $n \to 2$.

**Two cycles.** There is a "long cycle" $1 \to 2 \to \cdots \to n \to 1$ of length $n$, and a "short cycle" $2 \to 3 \to \cdots \to n \to 2$ of length $n-1$. Since $\gcd(n, n-1) = 1$, the graph is aperiodic; it is clearly strongly connected. So $W$ is primitive.

**Walk lengths.** Since $(W^k)_{ij}$ counts walks of length $k$ from $i$ to $j$:

- For $j \geq 2$: every walk from $i$ to $j$ can be decomposed as a shortest path (length $d_{ij} \leq n-1$) plus copies of the two cycles. The set of achievable lengths is $d_{ij} + \langle n, n-1 \rangle$ where $\langle n, n-1 \rangle = \{an + b(n-1) : a,b \geq 0\}$.

- For $j = 1$: every walk from $i$ to $1$ must traverse the edge $n \to 1$, so it consists of a path from $i$ to $n$ (length $n - i$) followed by $n \to 1$ (length 1) plus copies of the two cycles. The achievable lengths are $(n - i + 1) + \langle n, n-1\rangle$. The shortest walk from $1$ to $1$ has length $n$ (the long cycle).

**Frobenius number.** $g(n, n-1) = n(n-1) - n - (n-1) = n^2 - 3n + 1 = (n-1)(n-2) - 1$. So every integer $\geq (n-1)(n-2)$ lies in $\langle n, n-1 \rangle$.

**Threshold for $(W^k)_{11} > 0$.** We need $k = n + an + b(n-1)$ for some $a, b \geq 0$, i.e., $k - n \in \langle n, n-1 \rangle$. This holds for all $k \geq n + (n-1)(n-2) = n^2 - 2n + 2 = (n-1)^2 + 1$.

**$(W^{(n-1)^2})_{11} = 0$.** We need $(n-1)^2 = n + an + b(n-1)$, i.e., $n^2 - 3n + 1 = (a+b)n - b$. So $b \equiv -1 \pmod{n}$, giving $b \geq n-1$, hence $a + (n-1) = \frac{n^2-3n+1+(n-1)}{n} = \frac{n^2-2n}{n} = n-2$, so $a = -1 < 0$. No nonneg solution exists. ✓

**$(W^{(n-1)^2+1})_{11} > 0$.** We need $(n-1)^2 + 1 = n + an + b(n-1)$, i.e., $n^2 - 3n + 2 = (a+b)n - b$. Take $b = n-2$: $a + (n-2) = \frac{n^2-3n+2+(n-2)}{n} = \frac{n^2-2n}{n} = n-2$, so $a = 0$. ✓

**All other entries.** For $j \geq 2$, $d_{ij} \leq n-1$, so $(W^k)_{ij} > 0$ for all $k \geq (n-1) + (n-1)(n-2) = (n-1)^2$. In particular, all off-diagonal entries (and diagonal entries for $j \geq 2$) are positive at $k = (n-1)^2 + 1$.

**Conclusion.** $\gamma(W) = (n-1)^2 + 1$, establishing the lower bound. $\square$

---

### 2. Upper Bound: $\gamma(M) \leq (n-1)^2 + 1$ for All Primitive $M$

Let $M$ be a primitive $n \times n$ nonneg matrix with graph $G = G(M)$.

#### 2a. Graph-Theoretic Setup

- **Strong connectivity** (irreducibility): For any vertices $i, j$, there is a path from $i$ to $j$ of length $d_{ij} \leq n - 1$.

- **Aperiodicity**: For every vertex $j$, let $L_j$ denote the set of lengths of closed walks through $j$. Then $L_j$ is a **numerical semigroup** (closed under addition, contains 0) with $\gcd(L_j) = 1$.

  *Proof that $L_j$ is a semigroup:* If $\ell_1, \ell_2 \in L_j$ (closed walks through $j$), concatenating them gives a closed walk through $j$ of length $\ell_1 + \ell_2$. ✓

  *Proof that $\gcd(L_j) = 1$:* In a strongly connected graph, all vertices have the same period. Since the graph is aperiodic (period 1), every vertex has period 1. ✓

- **Generators of $L_j$**: The semigroup $L_j$ is generated by the lengths of simple cycles through $j$, each of which is at most $n$. So the minimal generating set $G_j \subseteq \{1, 2, \ldots, n\}$ with $\gcd(G_j) = 1$, and $g(L_j) = g(G_j)$ (the Frobenius number of the semigroup equals that of its generators).

#### 2b. Key Lemma: Frobenius Number Bound

> **Lemma.** For any set $G \subseteq \{1, 2, \ldots, n\}$ with $\gcd(G) = 1$, the Frobenius number satisfies $g(G) \leq (n-1)(n-2)$.

*Proof.* By strong induction on $n$.

**Base cases.** $n = 1$: $G = \{1\}$, $g = 0 \leq 0$. $n = 2$: $G \subseteq \{1,2\}$ with $\gcd = 1$ forces $1 \in G$, so $g = 0 \leq 0$. ✓

**Inductive step** ($n \geq 3$). Assume the lemma for all $n' < n$. Let $G \subseteq \{1, \ldots, n\}$ with $\gcd(G) = 1$.

**Case 1: $1 \in G$.** Then $g(G) = 0 \leq (n-1)(n-2)$. ✓

**Case 2: $n \notin G$.** Then $G \subseteq \{1, \ldots, n-1\}$, and by induction $g(G) \leq (n-2)(n-3) \leq (n-1)(n-2)$. ✓

**Case 3: $1 \notin G$ and $n \in G$.** Let $G' = G \setminus \{n\}$ and $d = \gcd(G')$.

  Note $G' \neq \emptyset$ (else $G = \{n\}$, $\gcd = n \neq 1$). Also $\gcd(n, d) = 1$ since $\gcd(G) = \gcd(n, d) = 1$.

  **Subcase 3a: $d = 1$.** Then $G' \subseteq \{2, \ldots, n-1\}$ with $\gcd(G') = 1$. By induction, $g(G') \leq (n-2)(n-3)$. Since $G' \subseteq G$, adding generators only enlarges the semigroup, so $g(G) \leq g(G') \leq (n-2)(n-3) \leq (n-1)(n-2)$. ✓

  **Subcase 3b: $d \geq 2$.** We apply the **Brauer–Shockley Theorem** (1962):

  > If $a$ is a positive integer, $S$ is a set of positive integers with $d = \gcd(S) \geq 2$, and $\gcd(a, d) = 1$, then
  > $$g(\{a\} \cup S) = g(a, d) + d \cdot g(S/d)$$
  > where $S/d = \{s/d : s \in S\}$.

  Applying this with $a = n$, $S = G'$:
  $$g(G) = g(n, d) + d \cdot g(G'/d).$$

  Since $\gcd(n, d) = 1$ and both $\geq 2$: $g(n, d) = nd - n - d$.

  The set $G'/d \subseteq \{1, 2, \ldots, n'\}$ where $n' = \lfloor (n-1)/d \rfloor$, and $\gcd(G'/d) = 1$.

  **If $n' \leq 2$**: Then $1 \in G'/d$ (since $\gcd(G'/d) = 1$ and all elements $\leq 2$), so $g(G'/d) = 0$. Thus:
  $$g(G) = nd - n - d.$$
  We need $nd - n - d \leq (n-1)(n-2) = n^2 - 3n + 2$, i.e., $d(n-1) \leq n^2 - 2n + 2 = (n-1)^2 + 1$. Since $d \leq n-1$ (as $d$ divides some element of $G' \subseteq \{2, \ldots, n-1\}$), we get $d(n-1) \leq (n-1)^2 \leq (n-1)^2 + 1$. ✓

  **If $n' \geq 3$**: By induction, $g(G'/d) \leq (n'-1)(n'-2)$. Since $n' \leq (n-1)/d$:
  $$(n'-1)(n'-2) \leq \left(\frac{n-1}{d} - 1\right)\left(\frac{n-1}{d} - 2\right) = \frac{(n-1-d)(n-1-2d)}{d^2}.$$

  Therefore:
  $$g(G) \leq nd - n - d + \frac{(n-1-d)(n-1-2d)}{d}.$$

  Expanding the fraction:
  $$\frac{(n-1-d)(n-1-2d)}{d} = \frac{(n-1)^2 - 3d(n-1) + 2d^2}{d} = \frac{(n-1)^2}{d} - 3(n-1) + 2d.$$

  So:
  $$g(G) \leq nd - n - d + \frac{(n-1)^2}{d} - 3(n-1) + 2d = d(n+1) - 4n + 3 + \frac{(n-1)^2}{d}.$$

  Define $\varphi(d) = d(n+1) + \frac{(n-1)^2}{d}$. We need:
  $$\varphi(d) \leq n^2 + n - 1.$$

  The function $\varphi$ is convex for $d > 0$. On the interval $d \in [2, (n-1)/2]$ (where $n' \geq 3$ requires $d \leq (n-1)/3$; but we can verify on the wider interval $[2, (n-1)/2]$), the maximum is at an endpoint:

  - **At $d = 2$**: $\varphi(2) = 2(n+1) + \frac{(n-1)^2}{2} = \frac{4(n+1) + (n-1)^2}{2} = \frac{n^2 + 2n + 5}{2}$.
    Need $\frac{n^2 + 2n + 5}{2} \leq n^2 + n - 1$, i.e., $n^2 + 2n + 5 \leq 2n^2 + 2n - 2$, i.e., $n^2 \geq 7$, i.e., $n \geq 3$. ✓

  - **At $d = (n-1)/2$**: $\varphi((n-1)/2) = \frac{(n-1)(n+1)}{2} + \frac{2(n-1)^2}{n-1} = \frac{n^2-1}{2} + 2(n-1) = \frac{n^2 + 4n - 5}{2}$.
    Need $\frac{n^2 + 4n - 5}{2} \leq n^2 + n - 1$, i.e., $n^2 + 4n - 5 \leq 2n^2 + 2n - 2$, i.e., $0 \leq n^2 - 2n + 3 = (n-1)^2 + 2$. ✓ (always true)

  By convexity, $\varphi(d) \leq n^2 + n - 1$ for all $d \in [2, (n-1)/2]$ when $n \geq 3$. Therefore $g(G) \leq n^2 - 3n + 2 = (n-1)(n-2)$. ✓

This completes the induction. $\square$

#### 2c. Completing the Upper Bound

For any vertices $i, j$ and any integer $m$:

- Take the shortest path from $i$ to $j$ (length $d_{ij} \leq n-1$).
- Append closed walks at $j$ of total length $m - d_{ij}$.

This gives a walk from $i$ to $j$ of length $m$ provided $m - d_{ij} \in L_j$. Since $L_j$ is a numerical semigroup with $\gcd(L_j) = 1$, all integers $> g(L_j)$ belong to $L_j$. By the Key Lemma, $g(L_j) \leq (n-1)(n-2)$.

Set $m = (n-1)^2 + 1$. Then:
$$m - d_{ij} \geq (n-1)^2 + 1 - (n-1) = (n-1)(n-2) + 1 > g(L_j).$$

So $m - d_{ij} \in L_j$, and $(M^m)_{ij} > 0$. Since this holds for **all** $i, j$, we conclude $M^{(n-1)^2+1} > 0$, hence $\gamma(M) \leq (n-1)^2 + 1$. $\square$

---

### 3. Conclusion

The lower bound is achieved by the Wielandt matrix ($\gamma(W) = (n-1)^2 + 1$), and the upper bound $\gamma(M) \leq (n-1)^2 + 1$ holds for all primitive $n \times n$ nonneg matrices $M$. Therefore:

$$\max\,\gamma(M) = \boxed{(n-1)^2 + 1}.$$
