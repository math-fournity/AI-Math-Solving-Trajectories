Consider a hypercube of dimension $2n$ with $2^{2n}$ vertices, where each vertex is represented by a binary string $(a_1,a_2,\ldots,a_{2n})$. Two vertices are connected by an edge if they differ in exactly one coordinate. Initially, there is one ant at each vertex. Each ant aims to move to the vertex $(a_{n+1},a_{n+2},\ldots,a_{2n},a_1,a_2,\ldots,a_n)$ by fixing the foremost differing bit at each step. Each edge can be traversed by only one ant per second, and each traversal takes one second. Determine the minimum time required for all ants to reach their destinations.
