Let $K$ be an algebraic number field with ring of integers $\mathcal{O}_K$, and $\mathfrak{m}$ a module of $K$. The class group of $K$ is defined as the quotient $J_K/P_K$, and the class number of $K$ is the order of its class group. The ray class group of $K$ with respect to the module $\mathfrak{m}$ is defined as the quotient $J_{K}^{\mathfrak{m}}/P_K^{\mathfrak{m}}$. Is the order of the ray class group always bounded by the class number? In other words, for any module $\mathfrak{m}$, do we always have $\lvert J_{K}^{\mathfrak{m}}/P_K^{\mathfrak{m}} \rvert \leq \lvert J_K /P_K\rvert$?
