# Proof: Universal Lebesgue Measurable Function for All Borel Functions

## Problem

Is there a Lebesgue measurable function $F: \mathbb{R}^2 \to \mathbb{R}$ such that for every Borel function $f: \mathbb{R} \to \mathbb{R}$, there exists some $y_f \in \mathbb{R}$ with $f(x) = F(x, y_f)$ for all $x$?

## Answer

$$\boxed{\text{Yes}}$$

## Proof

### Step 1: Cardinality Setup

The set of all Borel functions $f: \mathbb{R} \to \mathbb{R}$ has cardinality $\mathfrak{c}$ (the continuum). This is because the Borel $\sigma$-algebra is generated by countably many sets, so there are $\mathfrak{c}$ many Borel sets, and each Borel function is determined by the preimages of rational intervals, giving at most $\mathfrak{c}^{\aleph_0} = \mathfrak{c}$ many Borel functions.

Let $C \subseteq [0,1]$ denote the **Cantor set**. Key properties of $C$:
- $C$ is **Lebesgue null**: $\lambda(C) = 0$.
- $|C| = \mathfrak{c}$ (the Cantor set has the cardinality of the continuum).

Since there are $\mathfrak{c}$ many Borel functions and $|C| = \mathfrak{c}$, we can index all Borel functions by elements of $C$. Specifically, using the Axiom of Choice (available in ZFC), there exists an enumeration $\{f_y : y \in C\}$ of all Borel functions $f: \mathbb{R} \to \mathbb{R}$, where each Borel function appears at least once.

### Step 2: Construction of $F$

Define $F: \mathbb{R}^2 \to \mathbb{R}$ by:

$$
F(x, y) = \begin{cases}
f_y(x) & \text{if } y \in C, \\
0 & \text{if } y \notin C.
\end{cases}
$$

### Step 3: Universality

For any Borel function $f: \mathbb{R} \to \mathbb{R}$, by construction there exists $y_f \in C$ such that $f_{y_f} = f$. Then for all $x \in \mathbb{R}$:

$$
F(x, y_f) = f_{y_f}(x) = f(x).
$$

So $F$ is universal for all Borel functions. $\checkmark$

### Step 4: Lebesgue Measurability of $F$

We show $F$ is Lebesgue measurable, i.e., for every Borel set $B \subseteq \mathbb{R}$, the preimage $F^{-1}(B)$ is Lebesgue measurable in $\mathbb{R}^2$.

We decompose:

$$
F^{-1}(B) = \underbrace{\big(F^{-1}(B) \cap (\mathbb{R} \times C)\big)}_{\text{Part A}} \cup \underbrace{\big(F^{-1}(B) \cap (\mathbb{R} \times C^c)\big)}_{\text{Part B}}.
$$

**Part B (the complement of $C$):** On $\mathbb{R} \times C^c$, we have $F(x,y) = 0$. Therefore:

$$
F^{-1}(B) \cap (\mathbb{R} \times C^c) = \begin{cases}
\mathbb{R} \times C^c & \text{if } 0 \in B, \\
\emptyset & \text{if } 0 \notin B.
\end{cases}
$$

In either case, Part B is a **Borel set** (since $\mathbb{R} \times C^c$ is Borel — $C$ is closed, so $C^c$ is open). $\checkmark$

**Part A (the Cantor set side):** Part A is a subset of $\mathbb{R} \times C$. We compute its 2-dimensional Lebesgue measure:

$$
\lambda_2(\mathbb{R} \times C) = \int_{\mathbb{R}} \lambda\big((\mathbb{R} \times C)^y\big)\, dy = \int_{\mathbb{R}} \lambda(\mathbb{R}) \cdot \mathbf{1}_C(y)\, dy = \int_C \infty\, dy = 0.
$$

The last equality holds because $\lambda(C) = 0$: the integral of any (even extended-valued) function over a null set is $0$. (Formally, every simple function $s \leq \infty \cdot \mathbf{1}_C$ satisfies $\int s\, d\lambda \leq c \cdot \lambda(C) = 0$ for some constant $c$, so the supremum is $0$.)

Since Part A $\subseteq \mathbb{R} \times C$ and $\lambda_2(\mathbb{R} \times C) = 0$, Part A is a **Lebesgue null set**, hence Lebesgue measurable. $\checkmark$

**Conclusion:** $F^{-1}(B) = \text{Part A} \cup \text{Part B}$ is the union of a Lebesgue null set and a Borel set, hence Lebesgue measurable. Since this holds for every Borel $B \subseteq \mathbb{R}$, $F$ is Lebesgue measurable. $\checkmark$

### Step 5: Summary

The function $F$ constructed in Step 2 satisfies:
1. **Lebesgue measurability**: $F$ equals a Borel function (the constant $0$) on the full-measure set $\mathbb{R} \times C^c$, and is arbitrary on the null set $\mathbb{R} \times C$. Any function that is Borel on a full-measure set is Lebesgue measurable.
2. **Universality**: Every Borel function $f: \mathbb{R} \to \mathbb{R}$ appears as a vertical section $F(\cdot, y_f)$ for some $y_f \in C$.

The key insight is that $\mathbb{R} \times C$ has 2-dimensional Lebesgue measure $0$ (because $C$ has 1-dimensional measure $0$), so $F$ can be defined **arbitrarily** on $\mathbb{R} \times C$ without affecting Lebesgue measurability. Since $|C| = \mathfrak{c}$ matches the cardinality of the family of all Borel functions, there is enough "room" in $C$ to encode every Borel function as a distinct vertical section.

$$\boxed{\text{Yes}}$$

### PROOF COMPLETE
