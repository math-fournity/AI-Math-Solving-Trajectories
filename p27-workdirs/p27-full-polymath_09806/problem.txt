In a specialized security facility, every digital access code is exactly four digits long, where each digit is limited to the values 1, 2, or 3. However, due to a hardware restriction on the keypad, no valid "Primary Code" is allowed to end with the digit 3. All four-digit sequences meeting these criteria (using only 1, 2, or 3, and not ending in 3) form the set of all active Primary Codes.
