# Proof: Is $X$ necessarily compact?

**Answer:** No. $X$ is not necessarily compact.

## Counterexample

Let $X = [0,1] \cup \mathbb{N}$, where $\mathbb{N} = \{1, 2, 3, \ldots\}$ is disjoint from $[0,1]$. Define the topology on $X$ as the topology generated by:

1. All open subsets of $[0,1]$ (with the usual subspace topology from $\mathbb{R}$), viewed as subsets of $X$.
2. For each $n \in \mathbb{N}$ and $N \in \mathbb{N}$, the set $\{n\} \cup (0, 1/N)$.

Equivalently, a set $W \subseteq X$ is open if and only if $W \cap [0,1]$ is open in $[0,1]$ (usual topology), and for each $n \in W \cap \mathbb{N}$, there exists $N \in \mathbb{N}$ such that $(0, 1/N) \subseteq W$.

Let $Y = [0,1] \subseteq X$.

## Verification

### The topology is well-defined

We check that the generating sets form a valid base (closed under finite intersections):

- **Two type-1 sets:** Intersection of open subsets of $[0,1]$ is open in $[0,1]$. ✓
- **Type-1 $\cap$ type-2:** $W \cap (\{n\} \cup (0,1/N)) = W \cap (0,1/N)$, which is open in $[0,1]$. ✓
- **Two type-2 sets, same $n$:** $(\{n\} \cup (0,1/N_1)) \cap (\{n\} \cup (0,1/N_2)) = \{n\} \cup (0, 1/\max(N_1,N_2))$. ✓
- **Two type-2 sets, different $n \neq m$:** $(\{n\} \cup (0,1/N)) \cap (\{m\} \cup (0,1/M)) = (0, 1/\max(N,M))$, open in $[0,1]$. ✓

### $X$ is second countable

A countable base is given by:
$$\mathcal{B} = \{B_k : k \in \mathbb{N}\} \cup \{\{n\} \cup (0, 1/N) : n, N \in \mathbb{N}\}$$
where $\{B_k\}$ is a countable base for $[0,1]$. This is a countable union of countable sets. ✓

### $X$ is $T_1$

We verify that every singleton is closed:

- **$\{n\}$ for $n \in \mathbb{N}$:** $X \setminus \{n\} = [0,1] \cup (\mathbb{N} \setminus \{n\})$. This is open: $[0,1]$ is open in $X$, and for each $m \neq n$, the set $\{m\} \cup (0,1)$ is an open neighborhood of $m$ contained in $X \setminus \{n\}$. ✓

- **$\{x\}$ for $x \in [0,1]$:** $X \setminus \{x\}$. The set $[0,1] \setminus \{x\}$ is open in $[0,1]$ (hence open in $X$). For each $n \in \mathbb{N}$, we need an open neighborhood of $n$ not containing $x$:
  - If $x = 0$: take $\{n\} \cup (0, 1/N)$ for any $N$; this does not contain $0$. ✓
  - If $x > 0$: choose $N$ large enough that $x \notin (0, 1/N)$ (i.e., $N > 1/x$); then $\{n\} \cup (0, 1/N)$ does not contain $x$. ✓

So every singleton is closed, hence $X$ is $T_1$. ✓

### $X$ is locally compact

- **For $x \in [0,1]$:** $[0,1]$ is a compact neighborhood of $x$ (it is compact in the usual topology, and the subspace topology on $[0,1]$ from $X$ is the usual topology, as verified below). ✓

- **For $n \in \mathbb{N}$:** Consider $K_N = \{n\} \cup [0, 1/N]$. The set $\{n\} \cup (0, 1/N)$ is an open neighborhood of $n$ contained in $K_N$. We claim $K_N$ is compact.

  *Proof of compactness of $K_N$:* Let $\mathcal{U}$ be an open cover of $K_N$. Some $U_0 \in \mathcal{U}$ covers $n$, so $U_0 \supseteq \{n\} \cup (0, 1/M)$ for some $M \in \mathbb{N}$. Then:
  $$K_N \setminus U_0 \subseteq [0, 1/N] \setminus (0, 1/M)$$
  - If $M \leq N$: then $(0, 1/M) \supseteq (0, 1/N]$, so $[0,1/N] \setminus (0, 1/M) = \{0\}$, a single point covered by one more open set.
  - If $M > N$: then $[0, 1/N] \setminus (0, 1/M) = \{0\} \cup [1/M, 1/N]$, a compact subset of $[0,1]$ (closed and bounded in $\mathbb{R}$). The sets $\{U \cap [0,1] : U \in \mathcal{U}\}$ form an open cover of this compact set in $[0,1]$, so finitely many suffice.

  In either case, $K_N$ is covered by finitely many elements of $\mathcal{U}$. ✓

### The subspace topology on $Y = [0,1]$ is the usual topology

If $W$ is open in $X$, then $W \cap [0,1]$ is a union of sets each of which is either some $B_k$ (open in $[0,1]$) or some $(0, 1/N)$ (open in $[0,1]$), hence $W \cap [0,1]$ is open in $[0,1]$. Conversely, every open subset of $[0,1]$ is open in $X$ by definition. ✓

### $Y = [0,1]$ is compact

$Y = [0,1]$ with the usual topology is compact (Heine–Borel). ✓

### $Y = [0,1]$ is dense in $X$

Every point of $X$ is in $\overline{Y}$:

- Points of $[0,1]$ are in $Y \subseteq \overline{Y}$ trivially.
- For $n \in \mathbb{N}$: every open neighborhood of $n$ contains $(0, 1/N)$ for some $N$, and $(0, 1/N) \subseteq [0,1] = Y$. So every neighborhood of $n$ intersects $Y$, hence $n \in \overline{Y}$. ✓

Therefore $\overline{Y} = X$, i.e., $Y$ is dense. ✓

### $X$ is not compact

Consider the open cover:
$$\mathcal{U} = \{[0,1]\} \cup \{\{n\} \cup (0, 1) : n \in \mathbb{N}\}$$

Each $\{n\} \cup (0,1)$ is open (it is the basic open set $\{n\} \cup (0, 1/1)$), and $[0,1]$ is open. This covers $X$: $[0,1]$ covers all of $[0,1]$, and each $n \in \mathbb{N}$ is covered by $\{n\} \cup (0,1)$.

However, no finite subcover exists. The set $[0,1]$ covers no points of $\mathbb{N}$ (since $\mathbb{N} \cap [0,1] = \emptyset$). Each set $\{n\} \cup (0,1)$ covers exactly one point of $\mathbb{N}$, namely $n$ (since $m \notin \{n\}$ and $m \notin (0,1) \subseteq [0,1]$ for $m \neq n$). Therefore, covering all of $\mathbb{N}$ requires infinitely many sets from the cover. ✓

## Conclusion

The space $X = [0,1] \cup \mathbb{N}$ with the topology described above is:
- Second countable ✓
- Locally compact ✓
- $T_1$ ✓
- Has $Y = [0,1]$ as a compact dense subset ✓
- But is **not compact** ✓

Therefore, $X$ is **not** necessarily compact.

$$\boxed{No}$$
