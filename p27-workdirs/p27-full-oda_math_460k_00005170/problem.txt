There is a partially ordered set \(\langle P, \prec \rangle\) which is the union of countably many centered sets but not the union of countably many filters. (A subset \(Q \subseteq P\) is centered if for any \(p_1, \ldots, p_n \in Q\) there is some \(q \preceq p_1, \ldots, p_n\) in \(P\). A subset \(F \subseteq P\) is a filter, if for any \(p_1, \ldots, p_n \in F\) there is some \(q \preceq p_1, \ldots, p_n\) with \(q \in F\).)
