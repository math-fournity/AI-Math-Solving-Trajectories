In a specialized logistics hub, a "Distribution Protocol of Grade 100" requires a collection of unique, positive integer-coded storage bins. For a collection of bins to satisfy this protocol, it must fulfill one specific condition: if you take every possible pair of bins from the collection and calculate the remainder when the capacity code of one bin is divided by the capacity code of another, the resulting set of remainders must exactly include every integer from 0 up to 100 (i.e., $\{0, 1, 2, \dots, 100\}$).
