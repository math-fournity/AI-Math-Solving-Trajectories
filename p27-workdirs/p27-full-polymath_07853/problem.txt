A high-tech server farm consists of a square grid of 100 columns and 100 rows of processors. Each processor is identified by a coordinate pair $(i, j)$ from the set $S=\{0, 1, \ldots, 99\}$. To ensure system stability, every possible "quad-cluster"—defined as a set of four adjacent processors $(i, j), (i+1, j), (i, j+1),$ and $(i+1, j+1)$—must contain at least one "active" security node. Note that the grid wraps around both horizontally and vertically (modulo 100), such that index $99+1$ is equivalent to index $0$.
