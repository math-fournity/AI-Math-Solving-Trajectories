Given two positive-valued functions $f, g: [0,1]\to(0,1)$, a pair $(f,g)$ is defined as good if, for every real number $r$, the set $Z_r := \{x ~\big|~ {g(x) / f(x)} = r \}$ has a measure of zero in $\mathbb{R}$. For example, if $f(x)=1/2$ and $g(x)=(x+1)/2$, the pair $(f,g)$ is good. Conversely, if $f(x)=1/2$ and $g(x)=3/4$, the pair $(f,g)$ is not good. Given a pair $(f,g)$ and a constant $\epsilon>0$, does there always exist a function $h: [0,1]\to [0,\epsilon]$ such that the pair $(f, g+h)$ is good? In other words, is it always possible to make a pair "good" by a slight perturbation?
