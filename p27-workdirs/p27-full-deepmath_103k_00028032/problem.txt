Let $f$ be a nonnegative function defined on the power set of the set of positive integers with the following properties: $f(X) \le f(Y) \le f(\mathbf{N})=1$ if $X\subseteq Y$; $f(X\cup Y)\le f(X)+f(Y)$; for each $X$ and each $y \in [0,f(X)]$ there exists $Y \subseteq X$ such that $f(Y)=y$. Given a set $A$ such that $f(A)<1$, determine if there exists a set $B$ containing $A$ such that $$ f(A)<f(B)<1 \,\,? $$
