Consider the quintic polynomial \(f(x) = x^5 + ax^4 + bx^3 + cx^2 + dx + e\) which is irreducible over \(\mathbb{Q}\). It has been verified that \(f(x)\) is irreducible over \(\mathbb{Z}_3\) using Eisenstein's Criterion with \(p=2\). The polynomial has only one real root. By applying Dedekind's Theorem, we find that there exists an element \(\sigma \in\) Gal\((f(x)/\mathbb{Q})\) which is a 4-cycle. Determine the Galois group of \(f(x)\).
