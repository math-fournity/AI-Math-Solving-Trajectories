A set $S$ of integers is called a Sidon set if for every four elements $a, b, c, d \in S$, the equation $a+b = c+d$ implies $\{a, b\} = \{c, d\}$. Let $n$ be the maximum possible size of a Sidon set $S \subseteq \{1, 2, \dots, 100\}$. Find the largest integer $k$ such that the proof strategy based on comparing the number of pairs $\binom{k}{2}$ to the number of possible differences $99$ (and accounting for 3-term arithmetic progressions) guarantees that no Sidon set of size $k$ exists in $\{1, 2, \dots, 100\}$.
