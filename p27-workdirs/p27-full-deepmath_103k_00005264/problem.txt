Let $M$ and $N$ be $n$-dimensional manifolds. Suppose $D_1, D_2, \dots, D_k$ are $n$-dimensional manifolds embedded in $M$ such that $\bigcup_{i=1}^k D_i = M$ and each $D_i$ is homeomorphic to $N$. Determine the minimum value of $k$. For example, if $M$ is a 2-dimensional torus and each $D_i$ is a 2-dimensional disk, the minimum value of $k$ is 3. What is the minimum value of $k$ if $M = L(5,2)$ and each $D_i$ is a 3-dimensional ball?
