A high-tech manufacturing plant utilizes a specialized 9x9 grid of automated storage lockers. Each locker is assigned a specific integer calibration code. The facility operates under a strict "Balance Protocol" for its logistics: if any 5 lockers are selected from the same horizontal aisle, the sum of their calibration codes must equal the code of a locker located within that same aisle. This identical rule applies to every vertical corridor as well (for any 5 lockers in a corridor, their sum must be the code of a locker in that corridor).
