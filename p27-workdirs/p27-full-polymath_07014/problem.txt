A high-security research facility uses a master key system based on cyclic digital codes. For a given security level $n$, a "validation sequence" is a string of $n^2$ digits, $x_1, x_2, \ldots, x_{n^2}$, where each digit is chosen from the set $\{1, 2, \ldots, n\}$. To ensure maximum entropy, a sequence is classified as "n-optimal" only if every possible ordered pair of digits $(a, b)$ with $a, b \in \{1, 2, \ldots, n\}$ appears exactly once as a pair of consecutive terms $(x_i, x_{i+1})$ in the sequence (treating the sequence as a circular loop where $x_{n^2}$ is followed by $x_1$).
