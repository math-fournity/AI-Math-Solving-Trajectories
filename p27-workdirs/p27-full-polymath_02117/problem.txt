Ariane and Bérénice play a game with residue classes modulo $n$. Starting with the residue class $1$, the players take turns replacing the current residue class $x$ with either $x+1$ or $2x$. Ariane starts the game. Ariane wins if the residue class $0$ is reached; Bérénice wins if she can prevent this indefinitely. Let $S$ be the set of all integers $n \in \{2, 3, \ldots, 100\}$ for which Ariane has a winning strategy. Find the sum of the elements in $S$.
