What is the largest value of the integer $n$, if the mass of any object can be determined using four suitable weights and a two-pan balance, given that we know the mass of the object in kilograms is an integer between 1 and $n$? (With the two-pan balance, we can perform as many measurements as we like, but we can only place the weights and the object to be measured on the pans, and we cannot cut either the weights or the objects to be measured.)
