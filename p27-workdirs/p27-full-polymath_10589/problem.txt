In the city of Arithmos, the high-security archives use a filing system based on "Sub-Sequencing." A master security code is said to "contain" a visitor’s access key if all the digits of the access key appear within the master code in their original relative order, even if other digits are interspersed between them. For instance, the master code 123 contains the access keys 1, 2, 3, 12, 13, and 23.
